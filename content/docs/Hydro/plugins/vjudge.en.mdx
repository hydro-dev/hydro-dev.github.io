## Remote Judging (VJudge)

<Callout type="error">
### Codeforces Compatibility Warning
Codeforces frequently updates its security and rate-limiting rules. As a result, the open-source VJudge plugin may be intermittently blocked or require manual source code modifications to bypass new firewall measures. 

**Codeforces Rate Limits**: Recent updates impose a strict daily submission limit per account. Unless specifically required, we recommend disabling Codeforces VJudge or using it sparingly.
</Callout>

### Quick Start: Codeforces

1. **Setup Domain**: Create a new domain named `codeforces`.
2. **Mount Domain**: Run the following MongoDB command to link the domain to the VJudge service:
   ```js
   db.domain.updateOne({_id: 'codeforces'}, {$set: {mount: 'codeforces'}});
   ```
3. **Configure Languages**: In the `codeforces` domain settings, select all submission languages prefixed with `codeforces`.
4. **Account Configuration**: Add your Codeforces credentials to the `vjudge` collection:
   ```js
   db.vjudge.insertOne({
     type: 'codeforces', 
     handle: '<your_handle>', 
     password: '<your_password>'
   });
   ```
5. **Restart Service**: Restart Hydro to apply the changes.

### Limitations
Remote judging sites often impose restrictions on request frequency and origin. Hydro does not guarantee 100% uptime for these third-party integrations. For detailed installation and troubleshooting, please refer to the latest community guides in the **Common Tutorials** section.
