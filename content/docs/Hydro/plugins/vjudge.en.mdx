<Callout type="warn">
Codeforces recently updated firewall rules. Submissions from the current open-source vjudge are blocked by the firewall and cannot be used directly, so you need to modify the source code yourself.
At the same time, a per-account daily submission limit was added. Unless you have special requirements, we recommend disabling Codeforces VJudge.

This document is outdated and kept only for archival purposes. The tutorial below is only an example. For detailed installation instructions, go to FAQS (Common Tutorials) for specific usage guidance.

Some supported remote sites impose limits on submission count / access frequency / request source. Hydro does not guarantee 100% availability of VJudge.
</Callout>

## Codeforces

After installing the plugin, create a domain named codeforces, then enter database command `db.domain.updateOne({_id:'codeforces'},{$set:{mount:'codeforces'}});`

In codeforces domain settings, configure `allowedLangs` as follows (in newer versions, select all languages prefixed with `codeforces` in allowed submission languages):

```
codeforces,codeforces.43,codeforces.52,codeforces.50,codeforces.54,codeforces.59,codeforces.61,codeforces.65,codeforces.9,codeforces.28,codeforces.32,codeforces.12,codeforces.60,codeforces.36,codeforces.48,codeforces.19,codeforces.3,codeforces.4,codeforces.51,codeforces.13,codeforces.6,codeforces.7,codeforces.31,codeforces.40,codeforces.41,codeforces.67,codeforces.49,codeforces.20,codeforces.34,codeforces.55
```

Insert the following entry into the vjudge table:

```js
{type:'codeforces', handle:'<codeforces login handle>', password:'<codeforces login password>'}
```
