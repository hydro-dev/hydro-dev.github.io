Starting from 2022/8/12, Hydro uses [nix]() by default to manage environments for **instances installed after that date**, to avoid host environment changes affecting judging.  
If your Hydro was installed before that, please install compilers via apt, restart sandbox with `pm2 restart hydro-sandbox`, and ignore this section.

Below is a brief guide to nix operations:

Use `nix-env -iA nixpkgs.<compiler-name>` to install a new compiler, then restart the sandbox with `pm2 restart hydro-sandbox` for it to take effect.

You can search for required compilers at [Nixos Search](https://search.nixos.org/packages).  
Examples of commonly used compilers:

```sh
nix-env -iA nixpkgs.coreutils nixpkgs.bash nixpkgs.gawk nixpkgs.unzip # 基础组件，已预装，不建议删除
nix-env -iA nixpkgs.gcc nixpkgs.fpc # C/C++ 和 Pascal，已预装，不建议删除
nix-env -iA nixpkgs.ghc # Haskell 
nix-env -iA nixpkgs.rustc # Rust
nix-env -iA nixpkgs.python3Minimal
nix-env -iA nixpkgs.python3Packages.numpy
nix-env -iA nixpkgs.pypy3
nix-env -iA nixpkgs.php
nix-env -iA nixpkgs.go # Golang
nix-env -iA nixpkgs.nodejs
nix-env -iA nixpkgs.openjdk_headless # Java
nix-env -iA nixpkgs.ruby
nix-env -iA nixpkgs.mono # C#
nix-env -iA nixpkgs.julia_17-bin # Julia
nix-env -iA nixpkgs.iverilog # Verilog
```

Use `nix-env -q` to view installed packages, then use `nix-env -e <compiler-name>` to remove a compiler.  
Be careful not to remove Hydro base components by mistake. Restart sandbox with `pm2 restart hydro-sandbox` after changes for them to take effect.

<Callout>
For some languages (especially Java and similar), compilation inherently requires longer CPU time, which is more obvious on single-core machines,
and compiling even A+B may take several seconds or even tens of seconds.  
Expected performance can be tested by manually running compile commands on the host:

```sh
javac -d /w -encoding utf8 ./Main.java && jar cvf Main.jar *.class
```

Also, some compilers may try to create many processes for multicore parallel compilation whenever possible. Ensure `processLimit` in judge settings is high enough,
otherwise compilation may fail because the compiler cannot create processes.  

When compilers use multicore parallel compilation, Hydro sums CPU usage across these processes as CPU resource usage. If compile timeout errors occur,
please adjust `compile_time_limit` (in ms) for the corresponding language in system settings.

Similarly, if memory limit exceeded errors occur, adjust `compile_memory_limit` (in MB) for the corresponding language.
</Callout>

<Callout>
After installing a `python` package using `sh nix-env -iA nixpkgs.python3Packages.xxxxx`, if dependencies cannot be found in the sandbox environment,
please follow the guide [Import Python packages into sandbox](https://hydro.ac/d/faqs/p/15) to update environment variables.
</Callout>

## Language-specific Time Limit Modifications

By default, the system gives Java and Kotlin 2x time limit. This behavior can be changed in language settings:

```yml
# 系统设置->语言设置
java:
  # ... existing settings ...
  time_limit_rate: 2
```

## Colored C/C++ Compilation Error Output

1. Confirm you installed a compiler that supports colored output;
2. In system settings, append `-fdiagnostics-color=always` to C/C++ compile commands

Example:

```yml
c:
  compile: /usr/bin/gcc -O2 -Wall -std=c99 -o ${name} foo.c -lm -fdiagnostics-color=always
```

## Advanced Environment Configuration

If you need more complex compiler environment configuration, we recommend writing a separate nix file.

```nix
{ 
  system ? builtins.currentSystem,
  pkgs ? import <nixpkgs> { system = system; }
}:

pkgs.buildEnv {
  name = "hydrojudge-rootfs";
  paths = with pkgs; [
    coreutils bash nix zip unzip gcc gawk
    # 上方包是评测所需要的，请勿删除，
    # 在下方列出你所需要的包，查找方式同上文：
    fpc python3 rustc
  ];
  ignoreCollisions = true;
  pathsToLink = [ "/" ];
  # 导出一些基本信息和部分编译器所需的 /etc/passwd
  postBuild = ''
    mkdir $out/buildInfo
    echo 'root:x:0:0:root:/root:/bin/bash' >$out/etc/passwd
    date >$out/buildInfo/timestamp
  '';
}
```

Copy the file above, save it as `default.nix`, and build it with `nix-build`.  
After building, a `result` folder will be generated. Note the path of that folder.  
Open `~/.hydro/mount.yaml` and replace `/root/.nix-profile` with the compiled `result` folder (switch to the new environment).  
Then save and restart the sandbox.  

If you need to change environment configuration later, just modify `default.nix`, run `nix-build` again, and restart sandbox to apply changes.  
Cache files produced during build can be cleaned with `nix-collect-garbage`.  

For more detailed nix language references, see [Nix Guide](https://nixos.org/guides/nix-language.html) and
[Nix Manual](https://nixos.org/manual/nix/stable/language/index.html).
