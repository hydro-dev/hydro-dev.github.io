## Environment Management

Starting from 2022-08-12, Hydro uses **Nix** to manage judge environments for new installations. This prevents host-environment changes from affecting judging consistency. 

If your Hydro instance was installed prior to this date, please install compilers via your distribution's package manager (e.g., `apt`), restart the sandbox with `pm2 restart hydro-sandbox`, and you may skip the Nix-specific sections below.

### Using Nix for Compilers

To install a new compiler, use `nix-env -iA nixpkgs.<compiler-name>`, then restart the sandbox with `pm2 restart hydro-sandbox`. 

You can search for available packages at [Nixos Search](https://search.nixos.org/packages). Common examples include:

```bash
# Core components (Installed by default; do not remove).
nix-env -iA nixpkgs.gcc nixpkgs.fpc nixpkgs.coreutils nixpkgs.bash nixpkgs.gawk nixpkgs.unzip

# Additional languages:
nix-env -iA nixpkgs.ghc                   # Haskell 
nix-env -iA nixpkgs.rustc                 # Rust
nix-env -iA nixpkgs.python3Minimal        # Python
nix-env -iA nixpkgs.python3Packages.numpy # Python + Numpy
nix-env -iA nixpkgs.openjdk_headless      # Java
nix-env -iA nixpkgs.nodejs                # Node.js
nix-env -iA nixpkgs.go                    # Go
nix-env -iA nixpkgs.php                   # PHP
```

**Managing Packages:**
- View installed packages: `nix-env -q`
- Uninstall a package: `nix-env -e <compiler-name>`
- After any change: `pm2 restart hydro-sandbox`

<Callout>
### Compilation Performance and Resource Limits

- **Java/JVM**: Languages like Java and Kotlin require significant CPU time for compilation. On single-core servers, even simple "A+B" problems may take several seconds to compile. You can verify native performance by running the compilation command manually on the host.
- **Process Limits**: Some compilers spawn many threads for parallel compilation. Ensure `processLimit` in your judge settings is high enough to prevent compilation errors.
- **CPU/Memory Limits**: For parallel compilers, Hydro aggregates CPU usage across all threads. If you encounter **Compile Timeout** or **Compile Memory Exceeded** errors, adjust the `compile_time_limit` and `compile_memory_limit` in your System Settings.
</Callout>

### Language Multipliers
By default, Java and Kotlin are given a 2.0x time limit multiplier. You can modify this in the **Language Settings** section of the Control Panel:

```yaml
java:
  time_limit_rate: 2.0
```

### Colored C++ Error Messages
To enable colored output in your submission logs:
1. Ensure your installed compiler supports it.
2. Add `-fdiagnostics-color=always` to your C/C++ compile commands in System Settings.

## Advanced Environment Configuration

For complex dependencies, we recommend using a custom `default.nix` file.

```nix
{ 
  system ? builtins.currentSystem,
  pkgs ? import <nixpkgs> { system = system; }
}:

pkgs.buildEnv {
  name = "hydrojudge-rootfs";
  paths = with pkgs; [
    coreutils bash nix zip unzip gcc gawk
    # List additional packages below:
    fpc python3 rustc
  ];
  ignoreCollisions = true;
  pathsToLink = [ "/" ];
  postBuild = ''
    mkdir $out/buildInfo
    echo 'root:x:0:0:root:/root:/bin/bash' >$out/etc/passwd
    date >$out/buildInfo/timestamp
  '';
}
```

**How to Apply:**
1. Save the file as `default.nix` and run `nix-build`.
2. This generates a `result` symlink. Note the path.
3. Update `~/.hydro/mount.yaml`, replacing `/root/.nix-profile` with your new `result` path.
4. Restart the sandbox: `pm2 restart hydro-sandbox`.

For more on Nix, see the [Nix Guide](https://nixos.org/guides/nix-language.html).
