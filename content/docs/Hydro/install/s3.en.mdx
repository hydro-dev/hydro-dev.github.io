## File Storage

Hydro stores user-uploaded files (test data, profile pictures, and attachments) in `/data/file/hydro` by default. 

<Callout>
Hydro instances deployed via the automated installation script are pre-configured with local storage.
</Callout>

### Changing Local Storage Location

If you need to move the file storage to a different disk or directory:
1. Stop the Hydro service (`pm2 stop hydrooj`).
2. Move the entire `/data/file/hydro` directory to the new path.
3. Start the Hydro service (`pm2 start hydrooj`).
4. **Immediately** navigate to the Control Panel > System Settings and update `file.path` to the new absolute path.
5. Restart the Hydro service once more.

## Using S3-Compatible Cloud Storage

Hydro supports Amazon S3 and S3-compatible services like Tencent Cloud COS and Alibaba Cloud OSS. 

<Callout type="warn">
### Manual File Migration
When switching from local storage to S3, you must manually upload existing files in `/data/file/hydro` to your S3 bucket.
</Callout>

### Tencent Cloud COS
1. Go to **Control Panel > System Settings > Bucket Settings**.
2. Configure the following fields:
   - **`file.type`**: `s3`
   - **`file.endPoint`**: `https://cos.<bucket-region>.myqcloud.com`
   - **`file.accessKey`**: Your Tencent Cloud `SecretId`.
   - **`file.secretKey`**: Your Tencent Cloud `SecretKey`.
   - **`file.bucket`**: Your bucket name (e.g., `hydro-1250000000`).
   - **`file.region`**: `Auto`
   - **`file.pathStyle`**: `false`
   - **`file.endPointForUser`**: `https://<bucket>.cos.<bucket-region>.myqcloud.com/`
   - **`file.endPointForJudge`**: `https://<bucket>.cos.<bucket-region>.myqcloud.com/`

### SeaweedFS
<Callout type="warn">
SeaweedFS installation and management require advanced system administration expertise. This is not recommended for non-technical users.
</Callout>

1. Ensure SeaweedFS is [installed and configured](https://github.com/seaweedfs/seaweedfs).
2. Configure the following in the Hydro Control Panel:
   - **`file.type`**: `s3`
   - **`file.endPoint`**: `http://127.0.0.1:8333`
   - **`file.accessKey`**: From SeaweedFS config.
   - **`file.secretKey`**: From SeaweedFS config.
   - **`file.bucket`**: `hydro`
   - **`file.pathStyle`**: `true`
   - **`file.endPointForUser`**: `/fs/`
   - **`file.endPointForJudge`**: `/fs/`

### Alibaba Cloud OSS
Alibaba Cloud OSS is fully supported via the S3-compatible configuration. PRs for a specific guide are welcome.
