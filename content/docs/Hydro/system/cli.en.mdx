## Overview

The Hydro CLI allows you to perform common administrative tasks directly from your terminal. 

<Callout>
- Ensure your database is configured before using the CLI.
- Commands must be run as the **root** user from the same directory used during installation.
- Syntax: `<required_parameter>`, `[optional_parameter]`. **Replace these placeholders (including the brackets) with your actual values.**
</Callout>

## Common Operations

### Create a User
*Note: We recommend using the Web UI (Control Panel > Import Users) for creating multiple users.*

```bash
# Syntax: hydrooj cli user create <email> <username> <password> <uid>
# Example: Create a user with UID 2. 
# Ensure the UID is an integer >= 2 and not already in use.
hydrooj cli user create admin@example.com admin p@ssword123 2
```

### Promote to Super Admin
```bash
# Grant full site administrative privileges to a user by UID.
hydrooj cli user setSuperAdmin 2
```

### Update User Privileges
```bash
# Syntax: hydrooj cli user setPriv <uid> <priv_level>
# Refer to the Privilege documentation for available levels.
hydrooj cli user setPriv 2 1
```

### Reset Password
```bash
# Forcefully change a user's password.
hydrooj cli user setPassword 2 new_secure_password
```

### Create a Judge Account
1. Create a regular user account using the steps above.
2. Note the `uid` returned by the creation command.
3. Grant judging permissions to that account:
```bash
hydrooj cli user setJudge <uid>
```
4. Enter these credentials into your judge machine's configuration file to establish a connection.

## Security and Blacklisting

### Ban a User
Set their privilege level to 0 to disable their account:
```bash
hydrooj cli user setPriv <uid> 0
```

### Ban IP or Email Domains
```bash
# Key formats: ip::1.2.3.4 or mail::example.com
# Duration is in months (integer). Use 0 for a permanent ban (default is 12).
hydrooj cli blacklist add <key> [duration]
hydrooj cli blacklist get <key>
hydrooj cli blacklist del <key>
```

## Additional CLI Commands

Most internal models can be triggered via the CLI. Below are some additional useful commands:

- `hydrooj cli user setUname <uid> <new_username>`: Update a username.
- `hydrooj cli user setEmail <uid> <new_email>`: Update a user's email.
- `hydrooj cli problem import <domainId> <path_to_package>`: Import a problem package into a domain.
- `hydrooj cli problem export <domainId>`: Export all problems from a domain.
- `hydrooj cli system set <key> <value>`: Modify a system configuration setting.
